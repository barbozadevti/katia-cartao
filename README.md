# Cartão Digital · Drª Kátia Portinho

Cartão digital interativo em uma única página (HTML + Tailwind): agendamento por WhatsApp nos três consultórios, site, salvar contato (.vcf) e compartilhar.

## Como usar

Abra `index.html` no navegador ou sirva a pasta:

```
python -m http.server 5340
```

Os dados do contato ficam no bloco `CARD` no fim do `index.html`.
